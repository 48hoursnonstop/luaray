# Vandermonde matrices

A Vandermonde matrix arranges powers of each input value into columns. It is
useful for evaluating and fitting polynomials.

## Signatures

| Call | Behavior |
| --- | --- |
| `lr.vander(x)` | Square matrix with decreasing powers. |
| `lr.vander(x, n, increasing)` | Select the number and order of columns. |
| `lr.vander(x, {n=..., increasing=true})` | Options-table form; `n` is lowercase. |

`x` must be one-dimensional. The default column count is its length.
`n` must be a nonnegative Lua integer and `increasing` must be a boolean.
When omitted, `increasing` is false.

## Build powers in decreasing order

```lua
local lr = require("luaray")
local x = lr.array({1, 2, 3}, "int32")
local powers = lr.vander(x)
assert(powers.shape[1] == 3 and powers.shape[2] == 3)
assert(powers:get(2, 1) == 4)
assert(powers:get(2, 2) == 2 and powers:get(2, 3) == 1)
```

The columns contain `x^(n-1), ..., x, 1`. Powers are generated by cumulative
multiplication in the promoted result dtype. The constant column is one even
when an input is zero, infinite, or NaN.

## Change the order or width

```lua
local increasing = lr.vander(x, {n=4, increasing=true})
assert(increasing:get(2, 1) == 1)
assert(increasing:get(2, 4) == 8)
assert(lr.vander(x, 0).shape[2] == 0)
```

Increasing order contains `1, x, x^2, ...`. Zero columns produce an empty matrix.
All results have independent, writable C-order storage, including inputs that
are reversed, strided, or read-only.

The output dtype is the common dtype of the input and native integer type.
On the tested 64-bit platform, narrow integers and booleans become `int64`,
float32 becomes float64, and complex64 becomes complex128. Combining uint64 with
the native signed integer type also produces float64, following NumPy promotion;
large unsigned values can therefore round during construction.

## Fit a quadratic polynomial

```lua
local samples = lr.array({0., 1., 2.}, "float64")
local values = lr.array({1., 4., 9.}, "float64")
local coefficients = lr.linalg.solve(lr.vander(samples), values)
assert(math.abs(coefficients[1] - 1) < 1e-12)
assert(math.abs(coefficients[2] - 2) < 1e-12)
assert(math.abs(coefficients[3] - 1) < 1e-12)
```

The decreasing column order makes the coefficients correspond to `x^2`, `x`,
and the constant term: this example recovers `x^2 + 2x + 1`.

## Compatibility

Available since **0.120.0-dev**. Exact-reference cases cover shapes, dtype promotion,
strides, input preservation, writable results, integer arithmetic and special
floating values. General random floating/complex comparisons use a preselected
relative tolerance of `3e-15`; metadata and ordinary references remain exact.

String and timedelta inputs can produce zero- or one-column matrices, as in the
pinned reference. More columns require a multiplication accumulation loop and
raise an error for those dtypes, including empty inputs. Datetime inputs have
no common dtype with the native integer type.

Object/structured arrays, foreign dispatch, Python subclass/warning protocols
and every host ABI remain outside the verified contract. The API remains
[partially compatible](api_inventory.md).
