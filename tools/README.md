# External reference checks

`reference-tests.sh` is used by `make reference-test`. It verifies the SHA-256 of
the immutable 0.116 source archive, then executes its frozen references against
the current native build. Downloaded data stays under the ignored `.dev/` directory.

Set `LUARAY_REFERENCE_ARCHIVE` to use an existing copy of that exact archive.
The full Python oracle and release tooling is preserved in the published source
package; it is not needed by this checkout.

Starting with 0.158, NumPy 2.5.4 changes 40 empty-axis quantile/median/percentile
cases from rejection to success. After verifying and extracting the immutable
archive, the script applies `compatibility/numpy254-reference.patch` using
`patch --fuzz=0`. Those exact cases gain value/dtype assertions generated by the
same deterministic generator with NumPy 2.5.4; all original numeric assertions
are retained. The archive itself is unchanged. This optional check requires
`patch`, alongside curl, tar and sha256sum. New 2.5.4 corpora are published in
the separate reference bundle.
