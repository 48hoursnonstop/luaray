## Unreleased

- Replaced the accumulated development log in the README with a project overview,
  build instructions, and a tested quickstart.
- Added an English/Spanish documentation index and separated current validation,
  source provenance, and historical reports.
- Marked generated oracle fixtures and vendored dependencies for GitHub review.
- Grouped upstream checksums under `compatibility/upstream/`. Release integrity
  manifests are now generated inside archives rather than tracked at the root.
