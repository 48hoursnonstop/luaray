# Contributing

See the [build and contribution guide](docs/development/contributing.md) for native
dependencies, compiler options, tests, and reference development.

For documentation, edit the Markdown sources under `docs/` and preview them with:

```sh
cd docs
npm ci
npm run dev
```

Build with `npm run build`. Keep English and Spanish guides aligned and execute
new Lua examples through the public API. Dependencies and site output stay ignored.
